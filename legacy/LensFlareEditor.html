idx3d III
LENS FLARE EDITOR

Parameter in applet tag: 3dsFile specifies the 3ds file to import.

  • 1 : Toggle Wireframe render mode
  • 2 : Toggle Flatshading render mode
  • 3 : Toggle Envmapped render mode
  • 4 : Toggle Phongshaded render mode
  • 5 : Toggle Phongshaded Envmapped render mode
  • 6 : Toggle Phongshaded Textured render mode
  • 7 : Toggle Phongshaded Textured Envmapped render mode

  • Mouse Drag : Rotate scene
  • Arrow keys : Move scene
  • + / - : Scale object
  • A : Activate Antialiasing
  • D : Deactivate Antialiasing
